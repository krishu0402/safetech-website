# SafeTech Solutions – SafeWork

SafeWork is an interactive health and safety training prototype developed by
SafeTech Solutions for a logistics and warehousing client in the automotive sector.

## Project Overview

The system is designed to provide an interactive training experience focused on
warehouse health and safety scenarios.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
